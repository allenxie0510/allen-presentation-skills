# OPC System Thinking — native PPTX reference

This package demonstrates the Learning Agent workshop system in a native,
editable PPTX. It repairs a user-supplied training deck by preserving its useful
content while rebuilding narrative rhythm, documentary imagery, alignment,
Chinese typography, practice, assessment, transfer, and speaker-note sources.
Allen Xie approved the `0.5.1` native PPTX profile for final delivery on
2026-08-31. The approval covers this production profile and its release gates;
it does not turn the synthetic concept project into real client evidence.

## What to reuse

- the quiet–working–peak sequence rather than a repeated left/right layout;
- room-scale type hierarchy and 12-column alignment;
- named documentary image slots with deliberate crop and focal position;
- a recurring international fractional-team cast with equal professional agency;
- populated system maps, review sheets, cards, and board labels rather than
  decorative or blank sticky-note clutter;
- native text and vector components that remain editable;
- practice, feedback, and 30-day transfer frames;
- full-slide render, contact-sheet review, and programmatic overflow checks.

## What not to reuse

Do not reuse the OPC project name, sample claims, fictional person, photographs,
or page-specific copy as evidence for another project. Replace all content and
assets from a verified project brief. The bundled photos are synthetic concept
illustrations, not documentary proof of a real client engagement.

## Files

- `opc-system-thinking-0.5.1.pptx` — 12-slide editable reference deck.
- `previews/contact-sheet.png` — cross-slide rhythm and silhouette review.
- `photos/` — six slot-ratio-aware, continuity-controlled synthetic concept photographs.
- `PROMPTS.md` — reusable cast, slot, semantic-artifact, and image-QA prompt set.
- `SOURCES.md` — provenance and disclosure register.
