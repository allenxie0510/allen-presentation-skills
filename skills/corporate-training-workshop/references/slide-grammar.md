# Corporate training and workshop slide grammar

| Learning job | Preferred visual | Required evidence or instruction | Avoid |
|---|---|---|---|
| Establish relevance | workplace scenario or consequence | learner context and performance gap | generic motivation quote |
| State outcomes | observable outcome list | behavior, condition, criterion | “understand” only |
| Orient the session | timed learning arc | activity and break timing | topic-only agenda |
| Explain a model | progressive mental model or hierarchy | source and scope | dense framework collage |
| Demonstrate | worked example with staged reveal | decision steps and rationale | unexplained final answer |
| Compare choices | good / weak example with criteria | equivalent context | caricatured bad example |
| Launch practice | activity card | goal, steps, time, groups, output | verbal-only instructions |
| Support practice | checklist, canvas, or job aid | task criteria | paragraph slide |
| Debrief | observation → meaning → application prompts | facilitator questions | “any thoughts?” only |
| Check learning | scenario decision or performance rubric | answer criteria and feedback | trivia quiz |
| Plan transfer | action / context / support / date grid | workplace opportunity | vague pledge |
| Evaluate | learning and transfer measure timeline | method, owner, timing | satisfaction score only |

Participant slides should be readable at a distance. Facilitator timing,
prompts, answers, and recovery options belong in notes or a facilitator guide.
