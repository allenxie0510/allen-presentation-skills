# 应用指南：从设计判断到交付

本指南是 Allen 的应用层编排，不是原研哉的原文、官方风格手册或已测量的通用最佳实践。选择当前任务相关的一节即可。

## 品牌或产品概念

从对象和实际使用场景起步。若资料不足，标明假设，先交付一版可讨论的方向。

1. 把 brief 改写为一句可检查的目标，例如“第一次打开包装的人能理解从哪里开始”，而不是“做得更高级”。
2. 找到一个被默认的前提，列出必须保留的识别资产与使用信息。
3. 选择最相关的模型；给出概念、主要触点、材料或媒介方向、需要删除与需要增加的内容。
4. 若取舍明显，可比较两条路线：让意义更开放，或让行动更明确；不要为了凑数量强行出方案。
5. 先识别对象的基础功能：例如包装需要保护、储存和开启，家具需要承重和稳定，再给出一次小规模原型验证：观察对象、具体任务、成功现象与失败信号。没有执行就写“待验证”。

一种可用输出结构：**问题重述 → 核心判断 → 具体方案 → 保留/改变的理由 → 原型验证**。

## 演示文稿与网页演示

先明确是现场演讲、独立阅读，还是评审决策；同样一页，三种场合所需信息不同。

- **开场页**：可用具体物件或观察提出问题；不要只放大词而不说明主题。
- **解释页**：将抽象概念落实到一次行为、一组对照或一个结构关系。图像承担解释，避免仅以“氛围感”填版面。
- **证据页**：保留结论、关键数据、单位、时间范围、样本或口径、来源及必要限定。可通过分组、层级、分步呈现和附录减少负担，不用删除证据换留白。
- **决策页**：明确建议、取舍、责任或下一步；不能让“开放解释”使读者猜测要做什么。
- **节奏**：依据推理安排疏密变化，允许需要比较时出现高密度页；不要把每页统一成一张图片加一句话。
- **形式**：从品牌要求、观看距离和内容推导字体、色彩、网格及图像裁切。无固定白色、米色、字号或留白百分比；不要声称这些来自原研哉。

实际制作时：先确定每页任务和信息层级，再制作文件、渲染、检查溢出与裁切、文字尺度、图表标签和投影可读性。若支持交互，检查操作状态与入口是否清楚。修复完成后交付真实成品与未解决限制。

若当前环境有 `presentation-core`、`ux-brand-case-study` 或其他用户已选演示技能，可让其承担文件生成和验证，本 skill 提供设计取舍。它们是可选协作能力，不是安装本 skill 的前置依赖。不得因为启用本 skill 自动改掉已有主题或格式；未安装它们时直接用当前环境的交付工具。

### 示例：AI 工作流培训的一页

用户资料：“输入材料→生成草稿→人工校验→发布”，要求保留蓝色品牌色。

应用推断：本页的问题是新手不知道什么时候需要自己做判断。保留蓝色，把人工校验作为清楚的决策点；用真实或明确标注的示例对照“草稿”和“校验后”结果。精简重复解释，保留责任、校验标准和发布条件。验证时让一位首次接触流程的人指出下一步及检查点；这个建议不是原研哉对 AI 的表态。

## 已有稿件的评审

先读取实际稿件，记录可定位的页面、区域或元素。没有看见原稿，就不要写“第 3 页太密”。

| 观察 | 影响 | 模型 | 具体改动 | 验证 |
|---|---|---|---|---|
| 填入实际看见的现象 | 谁在何种任务中遇到什么困难 | 最相关的一个模型 | 修改位置、对象与属性 | 怎样比较改前改后 |

优先提出最有影响的少量改动。先检查是否有值得保留的元素并说明理由；没有证据支持保留时据实说明，不为平衡评价强行肯定。数字如对比度、识别率或文字尺寸，只有测量或明确作为建议时才使用。

## 图片、海报与生成提示词

修改已有图片时，先查看原稿并以原图作为编辑输入，记录必须保留的文字与品牌元素；完成后对照检查尺寸、裁切及关键内容。二维码等功能元素保留可用原件并核验功能，不能只看外观相似。工具无法保留关键内容时改用可控局部编辑或排版；仍无法完成就说明限制和交付状态。需要新图时使用当前环境的生成能力；只要求提示词时交付提示词。不要把“原研哉风格”当作全部描述。

提示词应包含：传播任务、主体、一个可感知细节、空间关系、光线或材料、必须出现的文字与品牌限制、待避免的视觉噪声。文字准确性和图像效果分别核验；没有图像生成能力时直说只提供了提示词。

示例骨架：

> 为〔受众/场景〕制作〔媒介〕，使观者注意到〔具体关系〕。主体为〔对象与动作〕，通过〔材料/边缘/光线〕呈现〔感知目标〕。保留〔标题、品牌色、必要文字〕，在〔区域〕为阅读/联想留下空间。不得添加〔会干扰任务的元素〕。

上面的结构是应用设计，不是原研哉固定提示词。

## 快速取舍检查

- 若移除元素：它承担的事实、操作或识别功能由什么接替？
- 若留下空：读者能进入，还是只能困惑？
- 若引入质感：媒介真的呈现了它，还是只有描述词？
- 若用了文化符号：与当地生活有什么可说明的联系？
- 若称为改进：比较依据是什么，哪项仍待验证？
