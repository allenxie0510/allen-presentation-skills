# Slope Trace / 坡迹

Speech Pitch Deck 0.4.0 的正式默认主题。把“学习坡度”变成内容驱动的跨页轨迹：
标题与正文始终保持水平基线，只有承担机制推进的模块沿坡度变化。

封面和收尾页保持安静，问题与证据页逐步加压，机制页达到峰值；定量数据页仍使用
正交坐标，不把斜线误当成增长趋势。纪实图片以单一大槽进入，保留人物、电脑、
学习动作和关键物证。

优先用于产品愿景、创始人路演和需要“从目标到行动”记忆结构的现场演讲。选择后继续
读取 [art-direction.md](art-direction.md)、`theme.yaml` 与 `theme.css`。
