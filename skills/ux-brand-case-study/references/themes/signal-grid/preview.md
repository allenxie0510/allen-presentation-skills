# Signal Grid / 信号网格

编辑感、决策型、低噪声的产品经营网格。以黑白灰建立证据层级，Signal Lime
只标记真正改变资源配置的行动信号，低饱和紫蓝用于已验证结构与基准。标题使用
内嵌开源中文字体 Smiley Sans，离线 HTML 无需依赖用户本机字体。

0.5.0 增加 NOVA Flow 概念项目预览：统一纪实摄影、专属图片槽、显式裁切位置、
素材来源清单与真实感 QA。概念项目中的人物、场景、研究和数据均为演示内容，
不得作为真实案例使用。需要摄影或产品证据时继续读取
[image-realism-qa.md](image-realism-qa.md)。

优先用于：Product Roadmap Review、Industry Research Deck。

选择本主题后，继续读取 [design-system.md](design-system.md)、`theme.yaml` 与
`theme.css`。预览从场景目录的 `assets/theme-previews/` 读取真实渲染截图。
仅在用户将本主题列入候选后加载此文件。
