# Learning Agent / 学习智能体

Learning Agent 0.4.0 是 Corporate Training Workshop 的正式默认主题。它把
Agent 从通用科技想象转译为可练习、可委托、可验收的工作协议，并以真实感
办公纪实照片证明学习行为。

视觉系统使用冷白与钴蓝建立教学定位，以酸性绿标记学习动作和人类验收；
人物、任务卡、自然木桌和现场物料承担证据功能，不使用机器人、发光球、
装饰性网格或通用 SaaS 卡片墙。

正式参考示例位于 `assets/examples/learning-agent-0.4.0/`。示例为明确标注的
概念项目，不代表真实客户、部署成果或员工绩效数据。
