# Night Relay / 夜间接力

Speech Pitch Deck 0.4.0 的正式深色替代主题。通过黑场峰值、浅色证据页、蓝色 Agent
节点与薄荷色学习者确认节点，让“目标交给 Agent、练习交还给人”成为可记忆的责任接力。

深色只用于钩子、机制与系统峰值；取舍、证据和行动请求回到浅色。圆形接力结构在一套
十页演讲中最多出现两次，避免变成科技装饰。照片保留自然肤色和真实环境，不叠加蓝色
滤镜，不使用发光球或玻璃卡片。

优先用于现场产品演讲、创始人路演和需要强机制记忆点的舞台表达。选择后继续读取
[art-direction.md](art-direction.md)、`theme.yaml` 与 `theme.css`。
