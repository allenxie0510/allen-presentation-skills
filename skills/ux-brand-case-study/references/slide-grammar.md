# UX and brand case-study slide grammar

| Reasoning job | Preferred visual | Required evidence | Avoid |
|---|---|---|---|
| Summarize the case | challenge / role / outcome frame | scope and attribution | vague hero montage |
| Establish context | ecosystem, journey, or before-state | observed conditions | generic market collage |
| Show research | evidence clusters with method labels | method, sample, date | quote wallpaper |
| Reframe the problem | evidence → insight → design principle chain | traceable logic | unsupported “how might we” |
| Compare directions | alternatives and criteria matrix | trade-offs and decision | one polished option only |
| Show iteration | selected artifact sequence with learning | version and feedback | full process timeline |
| Explain UX | task flow, journey, or interaction sequence | user goal and tested behavior | disconnected screens |
| Explain brand | strategy → expression → system map | organizing idea and rules | logo construction alone |
| Demonstrate system | component or touchpoint grammar | consistency and variation rules | repetitive mockup gallery |
| Show change | fair before/after comparison | equivalent context | manipulated comparison |
| Report impact | outcome bridge with attribution labels | baseline, period, source | vanity metric cards |
| Reflect | what worked / limits / next learning | honest uncertainty | generic lessons learned |

Use images as evidence. Caption every artifact with the decision, behavior, or
system property it demonstrates.
