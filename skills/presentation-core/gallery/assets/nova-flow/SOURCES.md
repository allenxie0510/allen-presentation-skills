# NOVA Flow concept-project image sources

All assets in this directory are synthetic concept imagery generated for the
Signal Grid 0.5.0 theme preview. They do not document a real company, product,
research session, or customer. The visible preview must retain the disclosure
`SYNTHETIC CONCEPT PROJECT · 概念项目，场景与数据仅用于主题演示`.

Generation date: 2026-08-30

Generation workflow: OpenAI built-in image generation, photorealistic-natural

Common direction: one fictional East Asian product team, one restrained design
studio, natural overcast light, black and neutral materials, and a single
acid-lime environmental accent. No logos, readable UI, or audience-facing text
were requested inside the generated images.

The exact production prompt set and narrative role for each v2 image are recorded
in [PROMPTS.md](PROMPTS.md). The original generated PNGs remain in the generation
runtime; the published assets are quality-92 WebP derivatives.

## Reuse boundary

- Use these files only as clearly labeled demo assets.
- Do not present the people, research activity, metrics, or findings as real.
- For a user deck, replace them with user-provided or properly sourced project
  evidence whenever available.
- Keep image provenance beside the assets when redistributing the preview.
