# Silent Spectrum reference analysis

The nine user-provided images are treated as design evidence, not templates to
copy. No source brand, logo, image, navigation, proprietary typeface, or
signature composition is included in the output.

## Transferable principles

- Use a strict editorial grid, hairline rules, and labels that terminate on real
  alignments rather than decorative guide lines.
- Create breathing room through controlled negative space, not by withholding
  necessary evidence.
- Reserve extreme scale for a small number of titles, numbers, decisions, or
  sequence markers; working pages return to moderate type.
- Use color-inclined grays—warm paper, mineral, sage, and blue-gray—to create
  depth without gradients.
- Prefer dark primary text and charcoal secondary text on every light field.
- Express time, range, causality, and dependency with light vector lines, ticks,
  and nodes whose semantics are named.
- Let photo-led pages become either one intentional full field or a clearly
  cropped evidence slot. When photography is unnecessary, use authored vectors
  rather than generic stock imagery.

## Explicit non-copy list

- Reference logos, brand names, navigation bars, photos, and UI controls.
- Exact card sequences, month/date arrangements, service-icon sets, and website
  hero compositions.
- Proprietary fonts or a claimed exact font match.
- Any historical, market, staffing, or project number visible in the references.

## Silent Spectrum palette roles

- Primary ink: `#121416`
- Secondary charcoal: `#4A4F52`
- Warm field: `#F0EFEA`
- Mineral field: `#E2E4E1`
- Blue-gray field: `#DCE2E4`
- Moss signal: `#667267`
- Rule: `rgba(18,20,22,.18)`

White or near-white type is not used on light surfaces. A future dark peak page
may use light type only on an explicit opaque surface that passes 4.5:1.
